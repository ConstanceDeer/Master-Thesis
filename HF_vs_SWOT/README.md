# HF-radar and SWOT intercomparison

This folder contains scripts used to compare sea surface velocity measurements form the HF-radar and geostrofic currecents from SWOT mission.

## Contents

```text
HF_vs_SWOT/
├── get_residuals.py        # Code used to find difference (residuals) between HF and SWOT
├── hf_swot_analysis.py     # Code used to analyse the residuals
├── stats.zip               # files produced in get_residuals.py used in hf_swot_analysis.py
└── README.md
```
