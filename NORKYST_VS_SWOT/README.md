# Norkyst800 and SWOT intercomparison

This folder contains scripts used to compare geostrofic currents from the Norkyst800 ROMS and SWOT mission.

## Contents

```text
NORKYST_vs_SWOT/
├── geoid_process_raw.py        # Code used to load and save geoid files as *.nc files
├── Geoids_regrid.py            # Code used grid data onto same grid
└── README.md
```
