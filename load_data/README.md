# Data Download

This folder contains scripts used to automate the data download used for the Master's Thesis project.

## Purpose

The scripts in this folder automate the collection of raw data from the original sources to ensure reproducibility of the experiments and analyses presented in the thesis.

## Contents

```text
load_data/
├── load_hf.py        # Code used to load HF-radar data from MetNO online database
├── load_swot.py      # Code used to load/process SWOT ADT, with three different ref planes, based on the SWOT L2 data implimetation code from Jensen (2025)
└── README.md
```

Source

Jensen, S. N., Andersen, O. B., Ludwigsen, C. B., Gonçalves‐Araujo, R., & de Steur, L. (2025). Surface water and ocean topography (SWOT) observations unveil small mesoscale variability on the East Greenland shelf. Geophysical Research Letters, 52, e2025GL118573. https://doi.org/10.1029/2025GL118573
