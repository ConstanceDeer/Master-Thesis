# Data Download

This folder contains scripts used to automate the data download used for the Master's Thesis project.

## Purpose

The scripts in this folder automate the collection of raw data from the original sources to ensure reproducibility of the experiments and analyses presented in the thesis.

## Contents

```text
load_data/
├── load_hf.py        # Code used to load HF-radar data from MetNO online database
├── load_norkyst.py
└── README.md
```
